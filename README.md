# FOOD — Food Ordering & Delivery Website

A responsive frontend Food Ordering and Delivery web application built with React JS, React Router DOM, and pure CSS, recreating a modern food delivery UI design.

## Technologies Used
- HTML5
- CSS3 (Pure custom CSS, responsive Flexbox & CSS Grid, no external CSS frameworks)
- JavaScript (ES6+)
- React JS
- React Router DOM
- Vite

## Features Implemented
- **Responsive Navigation Bar:** Anchor links (`Home`, `Menu`, `Service`, `Contact`), live menu search bar, dynamic cart item badge counter, and Login / Sign Up navigation.
- **Hero Section:** Call-to-action buttons (`Order Now` and interactive `Order Process` breakdown) with floating food and delivery preview cards.
- **Services Section:** Reusable `ServiceCard` components displaying *Easy To Order*, *Fastest Delivery*, and *Best Quality*.
- **Dynamic Food Menu & Cart:** Category filtering (`All`, `Burger`, `Pizza`, `Salad`, `Noodles`, `Drink`, `Dessert`), `Show More / Show Less` toggle, `Add to Cart`, `+` / `-` quantity controls, and a slide-over Cart Drawer with total calculation and simulated checkout.
- **Testimonials Carousel:** Interactive customer review switcher using React state (`useState`).
- **App Promotion & Footer:** Mobile app promotion section and a footer featuring a validated Newsletter subscription form.
- **Signup & Login Pages:** Split-screen forms with email regex validation, password visibility toggle, Terms & Conditions / Remember Me checkboxes, Back button, simulated social auth messages, and automatic redirection to Home via `useNavigate`.
